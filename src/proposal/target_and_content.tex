\chapter{课题研究目标、研究内容和拟解决的关键性问题}

\section{课题研究目标}

\subsection{总体目标}

针对当前学术界在多FPGA硬件仿真领域的现有不足，本课题拟提出一种新型的多FPGA硬件仿真技术——SMART (Scalable Multi-FPGA Automated Replayable Technology)。本研究的核心目标是：在物理上分布、时序上离散的多FPGA环境中，构建逻辑统一、全状态可见且时序可控的仿真模型。SMART旨在面向多层次（片内、跨片、跨服务器）与多粒度（模块级、网表级）的大规模SoC仿真需求，解决多FPGA硬件仿真中存在的电路划分、结构集成、互连方法的技术挑战。这些技术挑战分别对应SMART中的三个技术点：

\begin{enumerate}
    \item \textbf{大规模可重放集成技术}：同时解决传统单FPGA仿真系统在处理大规模SoC时的容量瓶颈问题，和多FPGA原型验证系统的可调试性问题。目标是实现跨FPGA的大规模全系统范围内的时钟精确与比特精确的状态重放，确保在软件端能够精确复现硬件在任意时刻的内部信号行为，为SoC级的软硬件协同验证提供“零盲区”的调试能力。
    
    \item \textbf{自适应粒度的自动化划分技术}：解决现有划分技术仅支持特定层级（如仅网表级或仅模块级）输入的局限，目标是提出一种支持从模块级到网表级自适应粒度的划分方法。同时通过自动化技术，消除硬件仿真部署过程中繁琐的人工干预。目标是构建从用户RTL设计输入，到划分后的RTL输出的全自动化划分流程。
    
    \item \textbf{可扩展可移植的多FPGA互连技术}：打破现有跨FPGA通信的同构物理信道的假设，目标是提出一种物理信道无关的通信抽象层，使得用户端逻辑无需修改便可轻松适配不同层次的计算节点，如片上可重构区域、跨FPGA以及跨服务器等。支持异构物理链路结构，确保在不同的硬件平台上都能实现统一格式的数据传输与控制通信。同时支持树状的主机通信路径，提升多FPGA系统的可扩展性。
\end{enumerate}

\subsection{现有技术对比与本课题的改进优势}

为了明确本课题的研究定位，我们将REMUS与当前主流的学术界及开源FPGA仿真/原型验证框架进行多维度对比。表~\ref{tab:compare}所示，SMART在电路划分、结构集成、互连方法的技术挑战上，与现有学术系统相比均有显著提升。SMART的自动化划分流程支持可变粒度甚至自适应粒度选择，而FireAxe在划分阶段仍需手动指导，Hetero-ViTAL仅支持模块级粗粒度划分，DUOHUAFEN仅支持网表级划分。在集成层面，SMART是首个将扫描链与划分接口统一化的方案，实现统一的启停控制；其划分集成基于LI-TDM，既支持任意同步时序电路，又向外提供延迟不敏感接口，适用于同步与异步多FPGA系统。相比之下，FireAxe的LI-BDN接口控制逻辑复杂，而Hetero-ViTAL的LI通道限制较强，无法应用于任意电路的划分。在通信方法上，SMART的跨FPGA互连提供物理信道无关的流式互连协议，可适应异构链路结构；而Hetero-ViTAL依赖特定云平台，DUOHUAFEN与FireAxe均基于同构通信结构，通用性有限。而且，SMART还引入分层主机通信路径，支持多FPGA系统的统一控制与数据传输，提升了系统的可扩展性。REMU和DUOHUAFEN的主机通信均为单片直连，难以扩展至多FPGA场景。

\section{研究内容}

SMART的设计理念是“逻辑统一，物理解耦”。整体架构旨在屏蔽底层物理计算节点（FPGA/服务器）的数量与互连差异，向上层用户呈现一个逻辑上连续、行为上确定的虚拟仿真环境。SMART作为面向多粒度和多层次的多FPGA部署技术，旨在克服现有方案在电路划分、结构集成、互连方法的技术挑战。用户只需将自定义硬件逻辑接入SMART提供的标准化顶层接口（包括AXI存储器、串口、时钟等基础外设），无需额外修改即可进入完全自动化的处理流程。

SMART的运行流程如图\ref{fig:REMUS-framework}所示：首先对输入设计执行自动化的电路划分；随后对每个划分子模块进行结构集成，包括跨FPGA数据接口与扫描链集成；最后，在多级物理架构上构建统一的通信信道，并通过运行时软件实现协同执行、暂停恢复与波形重放等能力。

\subsection{电路划分：自适应粒度的全自动划分流程}

为了解决传统划分方法在处理复杂SoC时粒度僵化，通用性、自动化不足的问题，本课题将基于通用RTL设计一个自适应粒度（Adaptive Granularity）的全自动划分方案。具体涉及以下两个关键技术问题：

\begin{itemize}
    \item \textbf{多层级图模型构建}：研究如何将扁平的门级网表与层级化的模块视图融合，构建混合超图模型。对于内部连接紧密且资源适中的模块，保持其完整性以减少割边；对于资源巨大的模块，自动降级为网表进行细粒度拆解。
    \item \textbf{通用RTL的端到端支持}：研究如何将通用RTL设计与REMUS的划分流程无缝对接，实现RTL进RTL出的体验，以便能够独立集成到其他多FPGA流程之中。
\end{itemize}

\subsection{结构集成：基于LI-TDM与扫描链的统一集成技术}

划分完成后，REMUS自动进入结构集成阶段。该阶段包含划分集成与逻辑集成两部分。这是本课题的核心创新点。现有的集成技术通常将“跨边界接口封装（Encapsulation）”与“调试（Debugging）”作为两个独立模块，也鲜有研究将二者结合。因此本课题将重点研究扫描链与跨边界接口的融合集成架构。

如第一章所属，REMUS的扫描链的技术基础来自于REMU，跨边界接口拟采用DUOHUAFEN框架的LI-TDM。然而两者的控制语义不同导致了逻辑冲突，无法直接使用。因此，本课题将重点研究以下两个关键技术问题：

\begin{itemize}

    \item \textbf{控制逻辑统一}：研究如何复用LI-TDM的状态机来驱动扫描链的移位操作。在正常仿真模式下，LI-TDM负责跨片信号的时分复用传输；在调试模式下，利用LI-TDM已有的跨片通路，将分布式扫描链串联成全局扫描链，实现状态的注入与提取。
    
    \item \textbf{原子性暂停机制}：研究在多时钟域环境下的精确暂停技术。设计一种握手协议，确保当用户发出暂停指令或触发断点时，所有FPGA能够在一个逻辑周期内协同停止，保持系统状态的全局时钟一致性，这是实现确定性重放的物理基础。
    
\end{itemize}

为了增强集成流程的通用性与自动化，本课题还将研究如何将上述集成技术自动化地应用于划分结果。REMUS拟采用综合工具解析划分结果，进行自动化的集成流程，并生成最终可综合的Verilog，无需用户干预。

\subsection{互连方法：可移植可扩展互连通信结构}

通信阶段涉及FPGA间的运行时数据传输以及主机与FPGA间的控制通信两方面的技术。在 跨FPGA间通信上，现有技术均是基于同构的点对点链路，缺乏对异构链路与多层次架构的支持。因此，本课题将研究一种基于流式通信抽象的跨FPGA互连方法。而在主机通信方面，现有技术多为单片直连，难以扩展至多FPGA场景。因此，本课题还将研究一种分层主机通信路径，提升多FPGA系统的可扩展性。具体内容如下：

\begin{itemize}
    \item \textbf{可移植的异构通信系统的流式互连通信}：基于AXI-Stream协议定义统一的包格式，屏蔽底层传输介质的差异。无论底层是片内总线、GT收发器还是TCP/IP网络，上层逻辑均看到统一的数据流接口。
          
    \item \textbf{可扩展的主机同步拓扑}：针对大规模集群中主机接口受限的问题，研究基于树状拓扑的消息分发网络。利用FPGA之间的现有互连链路，复用数据通道传输控制指令（如Step, Reset, Snapshot），实现主机对数十个FPGA节点的时钟精确的广播控制与数据聚合。
\end{itemize}

\section{关键性问题}

基于上述研究目标与内容，本课题主要致力于解决以下四个关键性科学与技术问题：

\begin{enumerate}

    \item \textbf{如何实现基于通用RTL的自适应粒度全自动划分？} \\
    目前的划分工具要么需要用户深入了解设计细节进行手动切割，要么强制将设计打散为网表导致可读性丧失。拟解决的关键问题是建立一套智能评估模型，能够根据FPGA资源约束和设计拓扑特征，自动决策切割边界，实现“RTL进，RTL出”的黑盒式体验。
    
    \item \textbf{如何在有限资源下统一实现跨边界通信与全状态捕获？} \\
    在FPGA资源受限的情况下，同时实现复杂跨边界接口电路和全芯片扫描链插入是一个巨大的挑战。关键问题在于如何设计一种满足两者暂停语义的统一控制单元，将LI-TDM的接口电路与扫描链的移位寄存器机制，在控制逻辑层面上进行融合，在不显著增加面积开销的前提下，同时满足跨边界通信与全信号可见性的双重需求。
    
    \item \textbf{如何在有限的主机接口下实现逻辑时钟同步的多FPGA控制？} \\
    在大规模部署的场景下，FPGA的数目达到两位数，远超出主机PCIe的接口数目，必须要设计一种基于树状拓扑的消息分发网络。而在分发网络的基础上，为了向上层用户呈现一个虚拟的仿真环境，关键问题在于如何实现跨FPGA的逻辑时钟的全局同步，使得各FPGA节点能够在一个逻辑周期内协同工作，保持系统状态的一致性。
    
    \item \textbf{如何验证多FPGA仿真系统的可重放精度与可扩展性？} \\
          实现技术只是第一步，技术是否能进行工程实现，工程实现的性能也是一大难题。关键问题是如何基于SMART技术，搭建一套多FPGA仿真平台，并通过大规模SoC或者多核处理器设计进行验证，评估其在不同规模与粒度下的重放精度与扩展性能，确保其在实际应用中的有效性与可靠性。
          
\end{enumerate}
