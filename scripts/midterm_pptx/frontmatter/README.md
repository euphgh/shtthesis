# Native cover and acknowledgement source

This directory is an unpacked OpenXML package containing two slides, extracted
from the reviewed Academic Red frontmatter. `pack_frontmatter()` in
`../../build_midterm_pptx.py` packages these tracked sources during each build.
It does not read an existing PPTX or a cached build.

- `ppt/slides/merged01_slide1.xml`: cover text and native objects.
- `ppt/slides/merged01_slide3.xml`: acknowledgement text and native objects.
- `ppt/slideLayouts/`, `ppt/slideMasters/`, `ppt/theme/`: inherited layout and style.
- `ppt/media/`: institution logos, preserved without recoloring.
- Relationship and content-type files keep the editable package valid.

Keep XML text and relationship targets consistent. Do not add generated previews
or PPTX archives here. Full build and validation: `make -C thesis pptx` from the
REMUS repository root. The unused template Contents slide is not in the page list;
Contents is generated by `slide_contents.py`.
