# REMUS答辩PPT视觉规范

中期答辩统一使用Academic Red主题。构建方法、文件职责和Git边界见
[构建与维护](pptx-implementation-plan.md)，此处只规定视觉样式。

## 配色

| 用途 | Hex |
| --- | --- |
| 页面主标题 | `#C00000` |
| 标题下细分隔线 | `#C55A11` |
| 重点、关键箭头、指标 | `#ED7D31` |
| 辅助符号与状态流 | `#70AD47` |
| 正文 | `#1F1F1F` |
| 结构轮廓、次级标题 | `#333333` |
| 图注、备注、页码 | `#898989` |
| 局部强调浅底 | `#FFF3EF` |
| 方法区域浅底 | `#F1F7EC` |
| 普通面板浅底 | `#F5F5F5` |
| 主体背景 | `#FFFFFF` |

颜色维护在`scripts/midterm_pptx/theme.py`。代码中的历史颜色值仅用于映射，
不代表仍维护另一套主题。红色用于主标题，不把技术框图或芯片全部染红。
状态通过文字、符号和线型辅助区分，不能只依靠颜色。

## 字体与布局

- 16:9宽屏，13.333×7.5英寸，白底。左右页边距通常0.4–0.55英寸。
- 英文标题、正文和图表标签使用Arial；封面中文沿用院校模板字体。
- 主标题28–32pt，分区标题19–22pt，正文17–20pt，图表标签14–17pt，脚注与页码10–12pt。
  以当前已确认的逐页布局为准，不能为塞入长段落而持续缩小字号。
- 标题左对齐，下方橙棕细线约1.5–2pt。一页表达一个关键观点，保持留白。
- 方法页突出问题、方法和证据；实验页展示实际记录；规划页不使用表示完成的符号。
- 使用Path-Cut Number；区分DUT逻辑时钟和FPGA物理时钟、Local Dump与Global Snapshot。

## 图片与可编辑性

- 标题、正文、箭头、简单框图和数据图表尽量用PowerPoint原生对象。
- 组件复用`figure/ppt-assets/`中的红色主题PNG；图案采用深灰、绿、橙，保持透明背景和比例。
- 全局暂停时序图使用`figure/midterm-pause-timing.png`，完整等比插入，不裁去关键阶段。
- 实验截图、设备照片和校徽保持原色。实验数据和技术语义不能为配色而改变。
- 不使用整页截图替代可编辑幻灯片。新资产嵌入PPTX后，交付文件应可独立打开。
- 预览为构建产物，统一写入`build/pptx/`，不提交Git；实际构建输入资产继续跟踪。

## 视觉检查

查看最终合并稿的全部14页预览，检查长标题、富文本、参考文献、图表标签和透明图标，
重点排查文字裁切、对象重叠、图片拉伸、箭头方向及页脚碰撞。
OpenXML校验不能替代视觉检查；OfficeCLI启发式提示须结合实际PNG判断。
事实、初步观察和未来计划分别依据论文与实验记录，示意节点数不能当成已验证系统规模。
